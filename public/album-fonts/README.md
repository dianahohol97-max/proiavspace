# Шрифти конструктора альбомів

Повні TTF (кирилиця, зокрема Ґґ Єє Іі Її, «», №) з Google Fonts через пакети
`@expo-google-fonts/*` (npm). Вантажаться лише редактором альбомів і експортом
(PDF вбудовує підмножину гліфів, PSD посилається на PostScript-ім'я).

| Файл | Гарнітура | Ліцензія |
|---|---|---|
| CormorantGaramond-Medium.ttf | Cormorant Garamond Medium | SIL OFL 1.1 — `OFL-cormorant-garamond.txt` |
| Lora-Regular.ttf | Lora | SIL OFL 1.1 — `OFL-lora.txt` |
| PlayfairDisplay-Regular.ttf | Playfair Display | SIL OFL 1.1 — `OFL-playfair-display.txt` |
| Montserrat-Regular.ttf | Montserrat | SIL OFL 1.1 — `OFL-montserrat.txt` |
| GreatVibes-Regular.ttf | Great Vibes | SIL OFL 1.1 — `OFL-great-vibes.txt` |
| MarckScript-Regular.ttf | Marck Script | SIL OFL 1.1 — `OFL-marck-script.txt` |

OFL дозволяє вбудовувати шрифти в документи (PDF) і поширювати їх разом із
програмою; продавати самі файли шрифтів окремо не можна.
