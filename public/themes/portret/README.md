# «Портрет» — тимчасова пара «до / після ретуші»

«Після» — кадр `themes/48` (як і решта `public/themes`); `48-before-*` — **згенерована** для демо пласка версія того самого кадру (менше
контрасту й насиченості, підняті тіні), а не справжній сирий файл. Замінити на
реальну пару з `assets/portret` (див. `docs/THEMES_PHOTOS_NEEDED.md` §6).
