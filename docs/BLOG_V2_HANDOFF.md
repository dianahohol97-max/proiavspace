# Блог v2 — передача роботи (Частина 2)

Частина 1 (генератор v2, міграції 0035–0036, позначки тем) — готова в цій гілці.
Лишилось: **4 статті, які пише Claude сам** (не Gemini), по одній, у порядку 1 → 2 → 3 → 4.

## Домовленості
- Факти й ціни — лише з веб-пошуку, **кожне джерело відкрити**. Ціни — маркером
  `{{price 15.99 USD | https://…}}` (код додає ₴ за курсом НБУ, «станом на», посилання).
- Курс НБУ на день генерації (25.09.2026 за новинами: 1 $ = 44,97 ₴, 1 € = 51,12 ₴ —
  перевірити на bank.gov.ua).
- Автор — Ева Худюк (`author = 'eva-khudiuk'`), співавтор-фотограф опційний.
- Зберігати в Supabase `blog_articles` як `status='draft'`, `source='editor'`
  (не 'ai' — інакше додасться автоабзац посилань), з `seo_title`, `quality_report`, `sources`.
  `published_date` ставиться при натисканні «Опублікувати» — не чіпати.
- Нічого не публікувати, наявні статті не змінювати.
- Після кожної статті: звіт `npm run blog -- check <file.json> --query "…" --rates USD=…,EUR=… --targets targets.json --out out.json`
  + 3–5 місць, де не впевнена у фактах.
- `targets.json`: продуктові сторінки (не draft) з product-pages.ts + curated + опубліковані статті з БД
  (поточні слаги через legacy-slugs.json).
