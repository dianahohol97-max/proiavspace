# Тексти листів — PR 2 (чернетка на перегляд)

Звертання як на сайті: «ви» з малої літери, без «шановний». Кожен лист —
plain text (так працює `sendEmail`: html робиться з тексту автоматично).
`{ім'я}` — `profiles.display_name`; якщо порожнє — просто «Привіт!».
Посилання ведуть у кабінет: `{кабінет}` = `https://proiav.space/uk/dashboard/billing`.

Політика (рішення 26.09): кінець тарифу → **14 днів grace** з повним доступом
→ галереї **закриті для клієнтів**, фотограф бачить усе → через **60 днів**
після закриття файли видаляються. Листи: початок grace, закриття, за 30 / 7 / 1
день до видалення. Free — без строку.

## 1. Чек після оплати

**Тема:** `проЯв · оплата {сума} ₴ — тариф «{тариф}»`

```
Привіт, {ім'я}!

Оплата пройшла. Дякуємо, що з нами.

Тариф: «{тариф}» — {обсяг} сховища
Період: {місяць|рік}, {дата початку} – {дата кінця}
Сума: {сума} ₴{, з них {кредит} ₴ покрито реферальним кредитом}
Спосіб: картка {провайдер}, замовлення № {order_id}

{Автоплатіж підключено: наступне списання {дата}, {сума} ₴. Вимкнути можна в кабінеті будь-коли.
|Автоплатіж не підключено: тариф діє до {дата}, далі — 14 днів на повному ліміті, а потім акаунт стає безкоштовним.}

Кабінет і тарифи: {кабінет}
Квитанцію банку надсилає {провайдер} окремо. Якщо потрібен рахунок для ФОП — відповідайте на цей лист.

— проЯв
```

## 2. Невдале списання

**Тема:** `проЯв · не вдалося списати {сума} ₴ за тариф «{тариф}»`

```
Привіт, {ім'я}!

Сьогодні ми спробували списати {сума} ₴ за тариф «{тариф}», але банк відхилив платіж
(найчастіше — закінчився строк картки або не вистачило коштів).

Нічого не зникає. До {дата grace = сьогодні + 14 днів} усе працює як раніше:
галереї відкриті для клієнтів, ліміт {обсяг}.

Щоб тариф не перервався, оновіть картку до {дата grace}:
{кабінет}

Якщо не оновити:
– з {дата grace} галереї стануть недоступними для клієнтів (ви їх бачите й можете завантажити);
– з {дата видалення = grace + 60 днів} файли будуть видалені зі сховища.

Ми нагадаємо за 30, 7 і 1 день до видалення.

— проЯв
```

## 3. Кінець тарифу — початок grace

Надсилається, коли оплачений період або промо-місяць закінчився без автопродовження
(скасована підписка, оплата без збереженої картки, кінець промо).

**Тема:** `проЯв · тариф «{тариф}» закінчився — 14 днів усе працює як раніше`

```
Привіт, {ім'я}!

{Оплачений період тарифу «{тариф}»|Безкоштовний місяць «Базового» за імпорт} закінчився {дата}.

До {дата закриття = дата + 14 днів} нічого не змінюється: галереї відкриті для клієнтів,
ліміт {обсяг}, відео на місці.

Далі, якщо тариф не продовжити:
– {дата закриття}: галереї закриваються для клієнтів. Ви й далі бачите все в кабінеті
  й можете завантажити будь-яку галерею архівом;
– {дата видалення = закриття + 60 днів}: файли видаляються зі сховища назавжди.

Продовжити тариф — одна оплата, усе відкривається одразу:
{кабінет}

Не плануєте платити? Завантажте потрібні галереї до {дата видалення} — це безкоштовно.

— проЯв
```

## 4. Галереї закриті для клієнтів (день 14)

**Тема:** `проЯв · галереї закриті для клієнтів, файли зберігаються до {дата видалення}`

```
Привіт, {ім'я}!

Сьогодні закінчився перехідний період після тарифу «{тариф}». Ваші {N} галерей
закриті для клієнтів: за посиланням вони бачать повідомлення, що галерея тимчасово
недоступна.

Для вас нічого не зникло: усі галереї та файли є в кабінеті. Завантажити архів
будь-якої галереї можна безкоштовно.

Файли зберігаються до {дата видалення}. Після цієї дати вони будуть видалені зі
сховища, і відновити їх буде неможливо.

Відкрити галереї знову — оплатити тариф; вони стануть доступними за тими самими
посиланнями, паролі й вибрані клієнтами фото збережуться:
{кабінет}

— проЯв
```

## 5. Попередження про видалення — 30 / 7 / 1 день

Один шаблон, три теми.

**Теми:**
- за 30 днів: `проЯв · через 30 днів файли будуть видалені ({дата видалення})`
- за 7 днів: `проЯв · через 7 днів файли будуть видалені ({дата видалення})`
- за 1 день: `проЯв · завтра файли будуть видалені — останнє нагадування`

```
Привіт, {ім'я}!

{Через 30 днів|Через 7 днів|Завтра}, {дата видалення}, ми видалимо зі сховища файли
ваших галерей: {N} галерей, {M} файлів, {обсяг використаного}.

Це остаточно — після видалення відновити файли неможливо.

Два способи все зберегти:
1. Оплатити тариф — галереї одразу відкриються для клієнтів, файли лишаться:
   {кабінет}
2. Завантажити галереї архівом до {дата видалення} — безкоштовно, з кабінету:
   https://proiav.space/uk/dashboard

Якщо ці файли вам більше не потрібні — нічого робити не треба.

— проЯв
```

Для листа «за 1 день» додатковий рядок після першого абзацу:
```
Це останнє нагадування.
```

## 7. Оновити чинний лист «промо закінчується» (renew/route.ts)

Зараз на «ти» й обіцяє «файли не видаляються». Пропоную:

**Тема:** `проЯв · безкоштовний місяць «Базового» закінчується {дата}`

```
Привіт, {ім'я}!

Безкоштовний місяць тарифу «Базовий» за імпорт галереї закінчується {дата}.

Щоб лишитися на «Базовому» (100 ГБ, 129 ₴/міс), підключіть автоплатіж:
129 ₴ спишемо зараз, а оплачений місяць почнеться {дата}.
{кабінет}

Без автоплатежу після {дата} ще 14 днів усе працює як раніше, потім галереї
закриваються для клієнтів, а через 60 днів файли видаляються зі сховища.
Ми нагадаємо заздалегідь.

— проЯв
```

### Що ще зміниться в текстах разом із листами (для повноти)

«Файли не видаляються» / «назавжди лишаються» → «файли зберігаються 60 днів після
закінчення тарифу»: `landing/copy.ts` (fineprint, FAQ), `product-pages.ts`
(тарифи, FAQ, порівняння), `uk.ts`/`en.ts` (promoAutopayHint, autoRenewConfirm,
graceNotice), оферта `legal/copy.ts`, `llms.txt`, промпт генератора блогу.
