# Журнал тем сайту

Кожна тема — **стиль, а не ніша**. Структура в усіх темах однакова (візитка на
одну сторінку):

1. Перший екран: фото, імʼя, «фотограф», напрямки, місто, кнопка запису.
2. Портфоліо: 9–15 кращих кадрів, фільтр «Усі · Весілля · …», якщо напрямків 2+.
3. Пакети: 2–4 з ціною й складом + короткі умови (передоплата, строки, виїзд, що взяти).
4. Про мене: фото + 2–3 речення.
5. Відгуки (необовʼязково): 2–3.
6. Запис і контакти: форма, Instagram, Telegram, телефон.
7. (необовʼязково, вимкнено за замовчуванням) «Подарунки та друк» — між пакетами й «Про мене».

Теми відрізняються лише виглядом і анімаціями (3–4 власні ефекти). Обмеження:
перший екран без очікування JS, ≤ 8000 px на iPhone (≤ 9000 з подарунками),
Lighthouse Performance ≥ 90, контраст ≥ 4.5:1, reduced motion, без горизонтального
переповнення 375–1440.

Спільний код: `src/components/site/card/` (дані візитки, фільтр, умови, подарунки,
контакти). Спільні e2e: `tests/e2e/card-checks.ts` (`cardSuite(id)`).
Сервісний маршрут для перевірок: `/uk/e2e/themes/<id>` (лише з `E2E_THEME_PREVIEW=1`).
Міграція `0064_site_themes_v2.sql` (не застосована) дозволяє зберегти нові id тем.

Скріншоти/відео: `docs/themes/<id>/` (desktop 1440 і iPhone 13).
